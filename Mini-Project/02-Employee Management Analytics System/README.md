# Project Goal

You are working as a junior data analyst in a company.

HR, Finance, and Management teams need reports from the employee database.

&nbsp;

## Your task

Write SQL queries to generate those reports.

&nbsp;

&nbsp;

# Steps

1. Step 1 — Create Database
2. Step 2 — Create Table with columns (emp_id, emp_name , department, city , salary , joining_date , email)
3. Step 3 — Insert Sample Data
4. Step 4 — Real-Life Tasks
   1. Section A — HR Reports

      | Task No | Task                                           | Status |
      | ------- | ---------------------------------------------- | ------ |
      | Task 1  | Show all employee details.                     |
      | Task 2  | HR wants only: employee name, department, city |
      | Task 3  | Show all unique departments.                   |
      | Task 4  | Show all unique cities.                        |

   2. Section B — Finance Reports

      | Task No | Task                                                                                         | Status |
      | ------- | -------------------------------------------------------------------------------------------- | ------ |
      | Task 1  | Generate annual salary report... Output: employee name, monthly salary, annual salary        |
      | Task 2  | Generate salary after 10% increment....Output: employee name, current salary, revised salary |
      | Task 3  | Generate estimated yearly bonus:20% of salary                                                |

   3. Section C — Employee Directory

      | Task No | Task                                             | Output                                                        | Status |
      | ------- | ------------------------------------------------ | ------------------------------------------------------------- | ------ |
      | Task 1  | Create employee identity cards.                  | Rahul Sharma works in HR department... Hint: Use: CONCAT() or |        |
      | Task 2  | Create full profile string. Example:Rahul Sharma | Delhi                                                         | HR     |
